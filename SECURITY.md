# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Report suspected vulnerabilities through GitHub private vulnerability reporting. Do not open a public issue or publish working exploit details before coordinated disclosure.

Please include the affected version or commit, security impact, minimal reproduction steps, logs with secrets removed, and a suggested mitigation if known. Reports will normally be acknowledged within seven days.

Only test installations and accounts you own or have explicit authorization to assess. Do not access third-party data, disrupt services, or attempt persistence. A CVE or monetary reward is not guaranteed.
