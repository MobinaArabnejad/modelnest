# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub's private vulnerability reporting feature. Do not open a public issue or include working exploit details in a public discussion.

Include:

- affected version or commit
- security impact
- minimal reproduction steps
- logs or screenshots with secrets removed
- suggested mitigation, if known

Only test installations and accounts that you own or have explicit permission to assess. We will acknowledge reports within 7 days and coordinate disclosure after a fix is available.
